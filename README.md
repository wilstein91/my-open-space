## 안 나온 자리
- 의자 뒤 에어드레서 벽면이랑 천장 일부 — 그쪽은 아예 안 찍었습니다. 사진이 한 장도 없으니 점이 생길 수가 없고, 그냥 뻥 뚫린 채로 검게 남았습니다.
- 물체 테두리에 낀 까맣고 거친 노이즈 — 의자나 핸들 같은 앞에 있는 물건이랑 뒤쪽 벽이 만나는 선입니다. 사진마다 그 경계가 애매하게 찍혀서, 앞인지 뒤인지 헷갈린 점들이 삐죽삐죽 튀어나온 것 같습니다.
- 레이싱 시트 쪽 — 방 안쪽이라 빛이 잘 안 들어와서 어둡습니다. 어두우면 사진마다 같은 자리인지 알아보기가 어려워질 것 같은데, 그래서 점을 제대로 못 잡고 뭉개지거나 아예 걸러진 게 아닐까 싶습니다. (확실한 건 아니고 추측입니다)
