## 안 나온 자리
- 의자 뒤 에어드레서 벽면이랑 천장 일부는 촬영 중에 누락이 되었고, 장면이 한 장도 없으니 점이 생길 수가 없어서 뚫린 채로 검게 남은 것으로 보임.
- 물체 테두리에 낀 까맣고 거친 노이즈 — 의자나 핸들 같은 앞에 있는 물건이랑 뒤쪽 벽이 만나는 선임. 사진마다 그 경계가 애매하게 찍혀서, 앞인지 뒤인지 헷갈린 점들이 삐죽삐죽 튀어나온 것 같음.
- 레이싱 시트 쪽 — 방 안쪽이라 채광도 좋지 못하고 조명으로부터의 음영이 생기는 영역. 추측컨대, 어두우면 사진마다 같은 지점인지 분간이 어려워지므로, 점을 제대로 못 잡고 뭉개지거나 아예 걸러진 것 같음.
